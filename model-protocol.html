Gap Analysis
Weaknesses in Your Stack → How to Spawn

These are the coverage gaps in your current model stack (excluding Claude + Gemini) and exactly how to fix each one with the right free/NIM model.

⚠ No Free Vision for Charts GAP

OpenRouter free models mostly lack reliable vision. Your free tier is text-only for stock analysis.

✓ Fix: Spawn NIM Nemotron VL 8B Use llama-3.1-nemotron-nano-vl-8b-v1 from build.nvidia.com — free endpoint, vision-language for chart image analysis.
⚠ No Free Document OCR GAP

Annual reports, earnings PDFs, financial tables require structure-aware OCR — not available in base LLMs.

✓ Fix: Spawn NIM Nemotron OCR v1 Add nemotron-ocr-v1 from NIM. Table structure + layout extraction purpose-built for documents like BSE filings and annual reports.
⚠ No Free 1M Context Reasoning GAP

DeepSeek R1 has 64K context. Your free reasoning tier can't process ultra-long financial reports in a single pass.

✓ Fix: Spawn Nemotron 3 Super 120B (OR) nvidia/nemotron-3-super-120b-a12b:free — Quality 60, 1M context, free. Route long-doc reasoning here instead of DeepSeek.
⚠ No RAG Embedding Layer GAP

Claude + Gemini don't provide embeddings. Without a dedicated embedding model, your Supabase pgvector RAG is either absent or using OpenAI paid embeddings.

✓ Fix: Spawn NV-EmbedQA E5 v5 Free NIM endpoint nv-embedqa-e5-v5. Replace OpenAI embeddings — OpenAI-compatible API, drop-in for N8N RAG nodes.
~ Free Tier Rate Limit Overflow RISK

200 req/day per model. Under heavy Investogram load, you'll hit limits on key free models.

✓ Fix: Rotation Protocol in N8N Build a model rotation node: try Gemma 4 31B → fallback Nemotron 3 Super → fallback gpt-oss-120b. Distributes load across 3 free models = 600 req/day effective capacity.
~ No Audio/Speech Input MISSING

Neither Claude nor Gemini Flash handles real-time voice input in N8N workflows.

✓ Fix: Spawn Nemotron Voicechat (NIM) nemotron-voicechat on NIM — free endpoint. Use as a voice-to-intent layer that routes into your main N8N workflow trigger.
Implementation Plan
N8N Spawning Protocol

How to wire all these models into your existing N8N + Supabase + Claude stack.

1
NVIDIA NIM API Setup

Go to build.nvidia.com → API Keys → Generate key. OpenAI-compatible — add as HTTP Header Credential in N8N.

// N8N HTTP Request Node — NVIDIA NIM Base URL: https://integrate.api.nvidia.com/v1 Headers: Authorization: Bearer {{$credentials.nvidia_api_key}} Content-Type: application/json // Compatible with OpenAI node (set Custom API Endpoint) Model examples: nvidia/llama-3.3-nemotron-super-49b-v1.5 nvidia/nemotron-nano-9b-v2 nvidia/nv-embedqa-e5-v5
2
OpenRouter Free Model Rotation Node

Build a "Model Router" N8N sub-workflow that distributes load across free models to avoid the 200 req/day cap.

// N8N Function Node — Free Model Rotator const models = [ "google/gemma-4-31b-it:free", // Quality 65 "nvidia/nemotron-3-super-120b-a12b:free", // Quality 60, 1M ctx "openai/gpt-oss-120b:free", // Quality 55 "qwen/qwen3-coder:free", // Best code "meta-llama/llama-3.3-70b-instruct:free" // Best tools ]; // Round-robin based on hour of day to spread rate limits const modelIndex = Math.floor(Date.now() / 3600000) % models.length; return { model: models[modelIndex] };
3
Investogram Model Routing Logic
  • A
    User Query Arrives Classify intent: reasoning / code / vision / document / embedding / voice
  • B
    Route by Type Reasoning → DeepSeek R1 (free) or Claude (paid). Code → Qwen3 Coder (free) or Claude (paid). Vision → Nemotron VL 8B (NIM free). Document → Nemotron OCR v1 (NIM). Long-ctx → Nemotron 3 Super 120B (free, 1M).
  • C
    Check Rate Limits If primary free model at limit → rotate to backup. If all free exhausted → escalate to Gemini Flash (cheap paid).
  • D
    Embed + Store Use NV-EmbedQA E5 v5 (NIM free) → Supabase pgvector. Zero cost embedding layer.
  • E
    Final Synthesis High-stakes output (stock picks, analysis reports) → always route to Claude Sonnet 4.6 for final quality pass.
